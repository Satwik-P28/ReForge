## Security review findings

- Studio refuses non-loopback binds.
- Package paths canonicalized at compile time.
- Event propagation capped (`MAX_EVENT_DEPTH=32`).
- Expression evaluation depth-limited (Phase 1).
- Inspect/validate does not execute package `impl/` trees.
- Residual: no cryptographic signatures; exported runner is a trusted-build path once the user chooses to compile vendored crates.

## Demonstration results

Flagship path covered by `e2e_composition` + `e2e_export` (compose → operate → unlink policy → persist → export → clean build → re-run). Negative path: reject-on-delete blocks task deletion with live links.
