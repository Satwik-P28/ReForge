1.000**. This measures observed-versus-declared actions, not semantic
equivalence.

## Executable extraction

`runner.py` executes the twin. `implementation.py` embeds the observed machine,
persists state, and runs without `twin.json` or the reference program. The
held-out-input regression test passes. The package remains `partial`: typed
domain CRUD, unobserved semantics and rich invariants are not synthesized.
